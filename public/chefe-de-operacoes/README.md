# Chefe de operações — Neural Think

Apresentação web estática de dez slides, com estética editorial inspirada no distill.pub.

## Uso local

Abra `index.html` no navegador ou rode um servidor estático na pasta:

```bash
python3 -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Navegação

- Scroll vertical para avançar.
- Setas `←` e `→` (ou `↑` e `↓`) para trocar de slide.
- `Home` e `End` vão ao primeiro e ao último slide.
- Os pontos na lateral também são clicáveis.

O projeto é compatível com publicação direta no GitHub Pages.
